# Flexbox — учебная веб-страница

Одностраничный пример на HTML и CSS для практики Flexbox. Страница содержит навигацию и адаптивный ряд карточек по темам «Спорт», «Музыка», «Наука» и «Путешествия».

## Запуск

Откройте `index.html` в современном браузере. Сборка и внешние зависимости не требуются.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Разметка и стили страницы |

CSS размещён непосредственно в HTML-файле; при узком окне карточки переносятся, а навигация адаптируется под доступную ширину.
